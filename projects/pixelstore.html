Pixel Store.

A demo storefront built to show a complete Razorpay payment flow, from checkout to an invoice generated on the spot.

Live Demo ↗ GitHub ↗

How it works

  • Full Razorpay checkout flow, from order to confirmed payment.
  • Webhook-driven updates keep order status in sync, even if the browser closes.
  • Invoices on demand, rendered from a server-side Handlebars template.
  • Built from the database, so every invoice matches the stored order.
